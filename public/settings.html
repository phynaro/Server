Ideal Cycle Times (Seconds per Case)

What is Ideal Cycle Time?

Ideal Cycle Time (ICT) is the theoretical minimum time to produce one case under perfect conditions. It drives the Performance metric: Performance = (ICT × Cases Produced) / Running Time. Set it to the machine's rated throughput — e.g. 10 s/case = 360 cases/hour. A value of 0 will cause Performance to read infinity.
